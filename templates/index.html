About This Project

What is PhishGuard?

PhishGuard URL Phishing Detection System is an AI-powered web application designed to protect users from phishing websites. It uses machine learning to analyze URLs in real-time and classify them as safe or malicious.

Built as a full-stack project combining Flask (Python), scikit-learn for ML, and a modern glassmorphic UI. The system performs WHOIS lookups, DNS resolution, and extracts 12+ features from each URL to make accurate predictions.

How It Works

From paste to verdict in seconds. Here's what happens behind the scenes when you scan a URL.

1
Paste Your URL

Enter any suspicious link into the scanner. We auto-detect the protocol and www prefix.

2
Feature Extraction

We extract 12+ features: URL length, special chars, digit ratio, HTTPS status, subdomain count, and more.

3
AI Analysis

A trained Random Forest model with 100 decision trees votes on whether the URL is phishing or safe.

4
Instant Verdict

Get a clear Safe/Phishing verdict with confidence score, domain WHOIS info, and safety recommendations.

Privacy Policy

Last Updated: February 2026

1. Data Collection

PhishGuard collects only the minimum data necessary to operate: your username, email (for account creation), and URLs you submit for analysis. We do not sell or share personal data with third parties.

2. URL Analysis

URLs submitted for scanning are processed in real-time. Feature extraction is performed server-side. Scan results are stored in your personal history if you are logged in. Anonymous scans are not persisted.

3. WHOIS Lookups

Domain intelligence queries (WHOIS) are performed via standard public registrar databases. No personal browsing data is shared during this process.

4. Cookies & Local Storage

We use browser localStorage to persist your session credentials and theme preference. No third-party tracking cookies are used.

5. Security

Credentials are transmitted using Base64-encoded Basic Authentication over HTTPS. Passwords are hashed server-side using industry-standard algorithms. We recommend using strong, unique passwords.

API Documentation

All API endpoints require Basic Authentication via the Authorization header.

POST /api/detect

Scan a URL for phishing indicators.

Body: { "url": "https://example.com" }

Response: { "prediction": 0, "prediction_label": "Legitimate", "confidence": 94.2, "domain_info": {...} }

GET /api/auth/verify

Verify current session credentials & retrieve user info.

Response: { "user": { "id": 1, "username": "...", "is_admin": false } }

GET /api/history

Retrieve authenticated user's scan history.

Response: { "checks": [{ "url": "...", "prediction_label": "Phishing", "confidence": 97.1, "checked_at": "..." }] }

POST /api/auth/register

Create a new user account.

Body: { "username": "...", "email": "...", "password": "..." }
